A haunt for every
Claude Code session.

A little daemon that catches each conversation the moment it ends and stows it as clean, searchable markdown. Install once — every project, every folder, every session you run anywhere on your machine, archived automatically.

Install for Mac Documentation
Local by default · bring your own VPS or cloud · configure from the menu bar

# wires the Stop hook, schedules the safety-net sweep, # backfills every session you've ever had — one shot. $ python3 ~/.claude/haunt/archive.py install ◌ Haunt — installing ✓ wired Stop hook ~/.claude/settings.json ✓ scheduled daily safety-net 23:00 local · com.haunt.daily ✓ backfilled 717 historical sessions Haunt is live. Every session you end will be archived automatically. $
Or, inside any Claude Code session: /haunt install — same command, less typing.
  • Hook
    Catches each session the moment it ends.

    A Stop hook fires the instant Claude Code stops — async, so your prompt comes back immediately while Haunt writes the markdown in the background. Real-time, on-event, never on a polling timer.

  • Sweep
    Daily safety-net at 23:00.

    A LaunchAgent walks every session that touched today, picks up anything the hook missed, and writes a per-day index. Belt-and-suspenders for the rare hook failure.

  • Ship
    Lands wherever you point it.

    Local folder by default. Switch to your VPS over scp, a Vercel endpoint, or anything else by editing one config key — or flipping it in the menu-bar app.
